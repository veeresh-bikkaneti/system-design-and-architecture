## Findings
BLOCKING
- B1. The issue's own observed leak shapes (the TopK/Temp/CPU backend/Model: lines) bypass the gate when wrapped in a list, a table or a code fence, or when "Model:" trails a sentence. The skip rules meant to avoid false positives create the bypass: a small model that wraps its echo in a fence or bullets passes. This changes the acceptance condition "catches known leak shapes". Fix suggestion: apply the config-line and template-marker rules inside fences and lists (keep the skip only for role-label and `model:`/`seed` lines), strip list, bullet and markdown wrappers before matching, and match mid-line "Model:" at end of text. Add tests for these exact inputs.

NON-BLOCKING
- N1. Over-rejection of legitimate line-initial "Temperature:", "Seed =", "Model:" and "System:" definitions (safe fail). Cost is a NO_SOURCE where an answer was possible. Document it or narrow it.
- N2. Failing-first for the call site may be partly an import failure. Add a behaviour-only red check.
- N3. Normalisation gaps: unicode, zero-width and fullwidth characters, and homoglyphs. Low value now; revisit when the W1 mirror is built.
- N4. The R-01 prior-turn hardening is deferred and must be tracked explicitly.
