## "Override-grade" — operationalised numerically (advisor note 1)

Advisor note 1 for this branch requires "override-grade strength" to be a
number, not prose. It is defined here, before code, against the router's
existing constants (`src/ai/local/semantic/router.ts` `THRESHOLDS` at the
base — verified; Phase 1 interrogation §4 — verified):

- Lesson bar: `THRESHOLDS.lesson` = **0.45**. Clarify bar: 0.33.
- Override constants: `THRESHOLDS.override` = **0.62**, `THRESHOLDS.overrideVote` = **0.6** (the existing pair that lets a strong lesson beat an off-course vote).
- Name boost: `THRESHOLDS.nameBoost` = **+0.08**, applied to `best` for short questions naming a lesson.

**Definition (binding for this branch): a lesson match is override-grade iff its UNBOOSTED best-section similarity is ≥ 0.62** — i.e. `top.best − (nameBoost if the top lesson was name-boosted, else 0) ≥ THRESHOLDS.override`. The name boost is excluded from the measurement because it is a lexical pin for acronym-short questions, not semantic coverage: the measured leak case `install kubernetes` scores 0.639 boosted but **0.559 unboosted** (Phase 1 interrogation §7 probe — verified), so counting the boost would make the worst measured case override-grade and the intercept would never fire on it. Below 0.62 unboosted, the intercept wins — including at and above the 0.45 lesson bar (ties and weak matches). At or above 0.62 unboosted, the lesson survives and the intercept does not fire.

## Dual trigger — operationalised (Seat C condition 1)

Both signals must fire; either alone routes nothing new.

- **Imperative/regex signal (arming only):** the install/setup verb in verb position — the question starts with `install` / `set up` / `setup`, or matches `how do I install…` / `how to install…` / `how do I set up…` (and the same with `setup`). A noun use ("what is the ai setup netflix uses") does not arm it.
- **Semantic signal (embedding-derived; no new exemplars):** the k-NN intent vote winner is `tech` or `course`, OR the unboosted best lesson-chunk similarity is ≥ **0.15** (a proximity floor far below the 0.33 clarify bar: it evidences that the question embeds measurably inside Ben's technical neighbourhood — the weakest measured how-to case, `how to install docker on ubuntu`, has best 0.188, Phase 1 §7 — verified). The measured how-to cases split across both disjuncts: the bare/install phrasings vote `tech`/`course`; the two `how do I install docker` phrasings vote `off_topic` (0.56 / 0.59, §7) and qualify on proximity only — which is exactly why a vote-only signal would leave the leak half-open.
- **Exclusions (existing classes keep their existing routes):** tutor-setup questions (the router's dedicated tutor-setup block: `isTutorSetupQuestion`, including the AI-environment family — a question mentioning `ai` together with `env`/`environment` keeps its pin or its `parametric_fallback` outcome) are never intercepted; the intercept is placed after the rule layer and after the named-tag pins, and inside the off-course branch after the definite-tutor-setup pin, so no pin is stolen.
